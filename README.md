# זיהוי מתקפות סייבר

פעילות למסך מגע רחב (שלושה מסכים, 11520x2160) בשני חלקים. הפרויקט בנוי על React עם Create React App.

- **חלק ראשון – התאמה:** מימין תמונות ממוספרות, באמצע הכותרת ומונה ההתאמות, משמאל שמות המתקפות. לחיצה ארוכה על שם פותחת מקלדת מספרים להקלדת מספר התמונה. בסיום יש קונפטי.
- **חלק שני – "ומה המשמעויות?":** לכל מתקפה נחשפות 12 תגיות, שתיים לכל מכלול (ביטחון, אוכלוסייה, מידע לציבור, חינוך, תשתיות ולוגיסטיקה, כוח אדם), מפוזרות על שני המסכים הצדדיים.

## הרצה
1. מתקינים Node.js (גרסה 18 ומעלה).
2. בטרמינל של VS Code: `npm install`
3. `npm start` – נפתח בדפדפן בכתובת http://localhost:3000
4. לפרסום: `npm run deploy` (GitHub Pages). לגרסה סופית לכיתה: `npm run build`.

## עריכה
- `src/data.js` – המתקפות, ההסברים וטקסט מסך הפתיחה. מספר התמונה נקבע לפי הסדר ברשימה `ATTACKS`, ומתערבב בכל משחק חדש. להוספת מתקפה: תמונה ב-`public/images` ושורה בסוף `ATTACKS`.
- `src/impacts.js` – הגדרות המכלולים ו-12 התגיות של כל מתקפה (שתיים לכל מכלול). בלי תגיות למתקפה חדשה יוצגו תגיות כלליות.
- `src/Gallery.js` – המסך הימני. `src/Info.js` – האמצעי. `src/Titles.js` ו-`src/Keypad.js` – השמאלי והמקלדת. `src/MeaningGame.js` – החלק השני. `src/QuestionMarks.js` – סימני השאלה. `src/Confetti.js` ו-`src/sound.js` – קונפטי וצלילים.
- `src/styles.css` – צבעים (בראש הקובץ), גדלים ופונטים. הגדלים ב-vh, ולכן מתכווננים לגובה המסך.
- פונטים: קרנטינה לכותרות ומספרים, אסיסטנט לכל השאר. הם מותקנים עם הפרויקט (`@fontsource`) ולכן עובדים גם בלי אינטרנט.

## הצגה על שלושת המסכים (11520x2160)
- פותחים את הדפדפן על המסך המשותף ולוחצים F11 למסך מלא, או מפעילים Chrome במצב קיוסק: `chrome --kiosk http://localhost:3000`
- כל חלק הוא מסך אחד (3840x2160). כל הגדלים ביחידות vh.
- התמונות המקוריות ברוחב 1600 פיקסלים, ולכן על מסך 4K הן יראו מעט רכות. מומלץ להחליף בקבצים ברזולוציה גבוהה יותר ב-`public/images` (אותם שמות קבצים).

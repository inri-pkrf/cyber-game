# זיהוי מתקפות סייבר

משחק גרירה למסך מגע רחב (שלושה חלקים). שמות מתקפות נגררים אל התמונות, ולאחר התאמה נכונה עולה הסבר. הפרויקט בנוי על React עם Create React App.

## הרצה
1. מתקינים Node.js (גרסה 18 ומעלה).
2. בטרמינל של VS Code: `npm install`
3. `npm start` – נפתח בדפדפן בכתובת http://localhost:3000
4. לגרסה סופית לכיתה: `npm run build`, ואז `npx serve -s build` (או מעתיקים את תיקיית `build` לשרת כלשהו).

## עריכה
- `src/data.js` – המתקפות, ההסברים, השמות המסיחים וטקסט מסך הפתיחה (`INTRO`).
- תמונות: בתיקייה `public/images`. להוספת מתקפה, שמים תמונה שם ומוסיפים שורה ב-`ATTACKS` (`image: img('שם-הקובץ')`, `panel` 0, 1 או 2).
- `src/styles.css` – צבעים (בראש הקובץ), גדלים ופונטים. הגדלים ב-vh, ולכן מתכווננים לגובה המסך.
- `src/Panel.js` – הלוגיקה של חלק אחד במסך. `src/Chip.js` – הגרירה. `src/Intro.js` – מסך הפתיחה.
- הפונטים נטענים מ-Google Fonts ב-`public/index.html`. לכיתה בלי אינטרנט אפשר להתקין `@fontsource/karantina` ו-`@fontsource/assistant` ולייבא אותם ב-`src/index.js`.

## הצגה על שלושת המסכים (11520x2160)
- פותחים את הדפדפן על המסך המשותף ולוחצים F11 למסך מלא, או מפעילים Chrome במצב קיוסק: `chrome --kiosk http://localhost:3000`
- כל חלק הוא מסך אחד (3840x2160). כל הגדלים ביחידות vh, כלומר מתאימים לגובה המסך.
- התמונות המקוריות ברוחב 1600 פיקסלים, ולכן על מסך 4K הן יראו מעט רכות. מומלץ להחליף בקבצים ברזולוציה גבוהה יותר ב-`public/images` (אותם שמות קבצים).
